# 광고 인사이트 수동 기록

**2026-11-06 사용 중단:** 사용자 요청으로 인사이트 기록 메뉴·화면·입력/백업 기능을 제거했습니다. 이전 `#records` 링크는 성과 대시보드로 이동합니다. 브라우저에 이미 저장된 자료는 자동 삭제하지 않습니다. 아래 내용은 이전 구현의 보관 기록이며 현재 사용 안내가 아닙니다.

2026-11-06 사용자 선택: 자동 갱신은 회사 담당자의 정식 관리자 설정·광고 조회 권한 확보 이후로 미루고, 지금은 **광고 인사이트 캡처 화면**으로 과거 기록을 보관합니다. 새로운 계정·유료 서비스·AI API는 사용하지 않습니다.

## 사용하는 방법

1. **인사이트 기록** 메뉴를 엽니다: https://jbgolf-connection.jbgolfacademy.workers.dev/#records
2. **캡처 기록 추가**에서 PNG/JPG/WebP 이미지(8MB 이하)를 선택합니다. 수치는 자동 인식하지 않습니다. 화면을 보면서 직접 입력·확인합니다. 이미지나 수치를 나중에 보완할 수 있습니다.
3. 광고 구분 이름을 입력합니다. 실제 광고 이름을 모르면 기록용 이름을 사용합니다. 같은 광고의 이후 캡처에는 **후속 캡처 기록**을 눌러 같은 이름을 이어 씁니다.
4. 캡처 기준일과 집계 시작일·종료일은 확인되는 경우에만 입력합니다. ‘광고 25일 후 종료’나 ‘12월 9일 종료’는 광고 종료 예정 안내이며 집계 기간을 알려주지 않습니다.
5. 지출, 조회수 표시, 결과 종류와 결과 수를 확인하고 저장합니다. 없는 수치는 비워 둡니다. **조회수와 노출**, **웹사이트 방문과 링크 클릭**을 바꿔 기록하지 않습니다. ‘2만’처럼 반올림한 값은 그대로 입력합니다.
6. **백업 내보내기**로 이미지와 수치를 JSON 파일에 보관합니다. 다른 기기/브라우저에서는 **백업 가져오기**를 사용합니다. 가져오기 전에 건수·같은 ID의 덮어쓰기 건수를 확인하고 취소할 수 있습니다.

## 저장 범위

- 현재 사이트 주소의 현재 브라우저 프로필 IndexedDB에 저장합니다. 서버·D1·공개 GitHub 저장소에 업로드하지 않습니다. 로그인 정보도 이 저장소에 넣지 않습니다.
- GitHub Pages와 workers.dev는 별도 저장 공간입니다. 자동 동기화하지 않습니다. 비공개 브라우징, 브라우저 데이터 삭제, 기기 교체 및 브라우저의 저장 공간 회수로 자료가 사라질 수 있으므로 백업 파일을 따로 보관합니다.
- 백업에는 회사 광고 수치와 이미지가 포함됩니다. 공개 저장소·공개 사이트 자산에 넣지 않습니다.
- 최대 200건, 이미지당 8MB, 가져오기 파일 최대 64MB입니다. 실제 저장 용량은 기기마다 다릅니다. 한도·쓰기 실패를 성공으로 표시하지 않습니다.
- AI/OCR 외부 API·새 패키지·추가 권한·유료 기능은 도입하지 않았습니다.

## 집계 원칙

- 기간 미확인 자료는 개별 기록으로만 표시하고 주간·월간 합계나 전주 비교에서 제외합니다.
- 집계 기간을 고르면 시작일·종료일이 정확히 같은 자료만 요약합니다. 같은 광고 구분 이름은 마지막 저장 기록 1건을 사용합니다. 누적 캡처 여러 장을 모두 더하지 않습니다. 다른 광고에는 다른 이름을 사용해야 합니다.
- 요약은 해당 기간에 **기록한 광고**만을 대상으로 합니다. 계정 전체 실적이나 자동 수집 결과로 표시하지 않습니다. 검색은 아래 목록에만 적용합니다.
- 결과 종류는 각각 표시하고 도달은 합산하지 않습니다. 반올림·누락 조회수는 정확한 합계를 산출하지 않습니다. 누락과 실제 0은 구분합니다.
- **보고 복사**에는 수동 기록·집계 기간 확인 여부·캡처 기준일 및 반올림 표시값이라는 설명이 포함됩니다. 기존 합성 예시 자료와 수동 기록은 분리합니다.

## 이전에 제공한 두 광고

확인 가능한 수치는 사용자에게 전달하는 비공개 JSON 가져오기 파일로 정리합니다. 정확한 광고 이름·ID, 집계 기간, 캡처 기준일은 확인되지 않아 임의로 채우지 않습니다. 대화 속 원본 이미지는 로컬 파일로 제공되지 않아 JSON에 첨부되지 않습니다. ‘원본 미첨부’로 표시하며 나중에 붙일 수 있습니다. 실제 회사 광고비는 공개 소스/정적 자산의 초기값에 넣지 않습니다.

수동 기록 추가는 Meta 앱 등록·광고 조회 승인·자동 수집 완료를 의미하지 않습니다. 기존 연결 서버·D1·암호화 키를 유지합니다. 비밀번호나 인증 코드를 공유받지 않으며, 추후 계정 소유자가 직접 인증하거나 정당한 권한을 부여하는 방식으로 진행합니다.
