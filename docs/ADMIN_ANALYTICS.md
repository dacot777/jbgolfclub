# 비공개 방문 기록

성과 대시보드의 왼쪽 상단 방패 로고 **위 빈 공간**을 세 번 연속 누르면 관리자 로그인 화면이 열립니다. 지정된 비밀번호는 서버에서만 검증하며 소스·정적 번들·브라우저 저장소에 넣지 않습니다. 숨은 진입 위치와 별개로 조회 API는 인증을 요구합니다.

클릭 영역은 사이드바의 맨 위32px 전체 너비입니다. 상단 브랜드와 이 영역에서만 글자 선택·이미지 끌기를 막으며 일반 본문 선택과 로고 링크는 유지합니다. 이전 화면을 열어두었다면 새로고침해 최신 버전을 불러옵니다. [운영 배포 확인](DEPLOYMENT.md).

## 기록과 표시

- 익명 방문자 번호, 접속 시각, 브라우저·기기 종류, 열어본 메뉴와 메뉴별 활성 화면 체류 시간을 표시합니다. 시간은 한국 시간입니다.
- 같은 브라우저의 재방문은 서명된 익명 쿠키로 구분합니다. 이름·연락처·원본 IP·전체 User-Agent·외부 방문 경로·입력 내용은 수집하지 않습니다. 쿠키 삭제나 다른 브라우저 사용 시 다른 방문자로 표시됩니다.
- 다른 탭이나 최소화된 화면에서 보낸 시간은 제외합니다. 30초 간격 활동 신호와 메뉴 이동·화면 숨김·종료 신호를 저장합니다. 종료 신호를 받지 못하면 정확한 퇴장을 추정하지 않고 마지막 활동을 표시합니다.
- 관리자 페이지는 수집 대상에서 제외하며 로그인한 관리자의 익명 방문자는 통계에서도 제외합니다. 브라우저의 DNT·GPC 설정을 존중합니다.
- 오늘·최근 7일·최근 30일 조회와 페이지 이동을 제공합니다. 기록은 배포 후부터 쌓이며 과거 방문은 복원하지 않습니다. 30일이 지난 기록은 일일 cron과 방문/관리자 조회 시 제한된 배치로 정리합니다.

## 서버 설정

기존 Worker와 D1을 재사용합니다. `0004_admin_analytics.sql`은 관리자 세션·익명 방문자·방문·메뉴 활동·요청 제한 테이블만 추가합니다. 광고 자료와 Instagram 인증 테이블은 변경하지 않습니다.

Cloudflare Secret 바인딩:

| 이름 | 형식 |
| --- | --- |
| `ADMIN_PASSWORD_VERIFIER` | `v1$<무작위 16바이트 salt의 hex>$<SHA-256(salt + ':' + password)의 hex>` |
| `ADMIN_ANALYTICS_KEY` | 최소 32자의 무작위 키. 익명 쿠키 서명·요청 제한용 HMAC에 사용 |

실제 비밀번호·검증 해시·키는 문서나 저장소에 기록하지 않습니다. 기존 `TOKEN_ENCRYPTION_KEY`는 보존합니다. 새 바인딩이 없으면 수집을 시작하지 않으며 관리자 화면은 설정 대기를 표시합니다.

관리자 세션은 무작위 토큰의 해시만 D1에 보관하며 8시간 후 만료됩니다. 관리자 쿠키는 `HttpOnly; Secure; SameSite=Strict`, 익명 방문자 쿠키는 `HttpOnly; Secure; SameSite=Lax`로 30일 유지됩니다. 로그아웃에는 CSRF 검증, 로그인에는 IP 기반 키 해시별·전체 요청 제한을 적용합니다. 모든 관리자 응답은 `no-store, private`이며 비밀번호 없는 통계 요청은 401입니다.

수집 API는 동일 출처, JSON 크기·메뉴·이벤트 ID·순서·소유권·누적 시간 상한을 검증합니다. 쿠키 첫 발급 요청을 직렬화해 빠른 메뉴 전환에서도 한 익명 방문자로 유지합니다. 전송 실패는 공개 사이트 이용을 막지 않습니다.

## 문의·상담

운영 사이트의 `#inquiries`는 방문 기록과 같은 관리자 세션을 사용합니다. 메뉴에서 **문의·상담 → 새 문의**를 누르거나 기존 행에서 **수정**을 누릅니다. **인계 담당자**에서 미배정, 김여울 대리님, 김의현 원장님 중 하나를 선택하고 저장하면 목록과 담당자 필터에 반영됩니다.

새 문의나 기존 문의를 수정할 때 **지점**에서 하남·청담·서현 버튼을 누릅니다. 지점이 확인되기 전에는 **미지정**을 선택할 수 있습니다. 기존 문의는 수정 화면에서 삭제할 수 있습니다. 삭제 확인창 바깥을 누르면 수정 화면으로 돌아가고, **삭제하기**를 누르면 목록과 문의 건수에 반영됩니다.

`문의 채널`에는 연락을 받은 곳을, `유입 경로`에는 고객이 어디에서 보고 왔는지를 기록합니다. 고객이 광고를 보고 왔다고 확인했을 때 해당 광고를 연결할 수 있습니다. 목록 위의 **총 문의**는 선택한 조건에 해당하는 문의 건수입니다.

마이그레이션 `0008_inquiries.sql`로 기존 D1에 문의 테이블을 추가합니다. 이름, 연락처, 상담 메모와 다음 조치는 Worker에서 암호화합니다. 조회와 수정은 관리자 전용이며, 브라우저 저장소나 방문 통계에는 상담 내용을 보관하지 않습니다.

## 비용과 검증

추가 분석 서비스·패키지·유료 API·요금제 변경 없이 기존 Workers Free/D1 한도를 공유합니다. 한도에 도달하면 저장/조회가 제한될 수 있으며 자동 유료 전환하지 않습니다. [비용 원칙](COST_POLICY.md).

`npm run build`, `npm run build:worker`, `npm test`, `npm run test:worker`로 검증합니다. 테스트에는 별도 가짜 비밀번호와 합성 방문만 사용합니다. 실서비스 검증에서 만든 합성 방문은 정확한 테스트 ID로만 삭제하며 실제 방문 기록이나 광고 이력을 삭제하지 않습니다.
