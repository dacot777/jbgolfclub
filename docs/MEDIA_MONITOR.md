# 기사·블로그 워크스페이스

사용자 요청(2026-11-06): 회사 관련 기사와 블로그/개인 후기 글을 한눈에 확인합니다. 메뉴에 들어가면 자동으로 최신 검색을 확인하며 별도 갱신·검색 실행 버튼은 없습니다.

## 검색 키워드

JB GOLF CLUB, JB골프클럽, 제이비골프클럽, JB골프클럽청담점, JB골프클럽서현점, JB아카데미, JB골프아카데미, JB GOLF ACADEMY, JB ACADEMY — 9개를 각각 검색합니다. OR로 합치면 공개 검색의 누락이 커져 개별 검색을 사용합니다. 띄어쓰기·영문 대소문자를 정규화해 관련성을 확인하며, 일반적인 JB ACADEMY/JB아카데미는 골프 문맥도 확인해 동명 학원을 제외합니다.

## 화면과 갱신

- 기존 사이드바의 **기사**(`#news`), **블로그**(`#blog`)에서 바로 조회합니다. 기사에는 언론사, 블로그에는 블로그명/작성자를 표시합니다.
- 실제 원본 썸네일·제목·확인 가능한 게시일·해당 키워드·원문 링크를 카드로 제공합니다. PC 3열, 태블릿 2열, 모바일 1열입니다. 이미지가 없거나 열리지 않으면 ‘이미지 없음’, 정확한 날짜가 없으면 ‘게시일 미확인’으로 표시합니다.
- 메뉴 진입/재진입마다 API를 호출합니다. 9개 키워드가 순서대로 갱신되는 동안 이미 찾은 글은 계속 보입니다. 한 번 더 누르는 갱신 버튼은 없습니다. StrictMode 중복 요청은 합치며 다른 메뉴로 이동하면 화면의 이전 요청 결과를 무시합니다.
- 검색 실패는 정상 0건과 구분합니다. 일시 장애 시 기존에 찾은 글과 마지막 확인 시각을 유지하고 다음 진입에서 다시 확인합니다. 공개 검색에 노출되지 않은 글이나 비공개/로그인이 필요한 글까지 전수 수집한다고 보장하지 않습니다.

## 무료 수집·보관

공개 네이버 뉴스/블로그 검색 HTML을 Worker 기본 HTMLRewriter로 읽습니다. 뉴스의 대체 출처는 Bing News RSS입니다. 블로그는 회사 계정만 제한하지 않아 일반인의 공개 이용 후기·언급도 포함합니다. API 키·가입·유료 검색 API·AI API·이미지 생성·추가 npm 패키지를 사용하지 않습니다. 원문 전체를 복제하지 않고 검색 결과의 제목·출처·썸네일 주소·원문 링크만 보관합니다.

- `GET /api/media?kind=news|blog`는 고정된 9개 키워드만 검색합니다. 임의 URL/쿼리를 받아 프록시하지 않습니다.
- Workers Free CPU 한도를 고려해 요청 1개가 키워드 1개를 처리합니다. 응답의 refreshing=true 동안 브라우저가 자동으로 다음 단계를 조회합니다. 요청별 공급자 응답은 2MB·약 9~10초 이내로 제한합니다.
- 같은 종류의 수집은 D1 잠금으로 중복 실행을 줄입니다. 완료 후 30초 이내 재진입은 방금 확인한 결과를 사용합니다. 브라우저는 최대 18회·90초 범위에서 자동 후속 확인을 하며 무제한 요청하지 않습니다.
- 기존 무료 D1의 `media_items`, `media_refresh` 테이블만 사용합니다(0003 마이그레이션). 광고/인증 테이블·기존 Secret/cron은 변경하지 않습니다. URL·추적 파라미터를 정리하고 중복 글은 병합합니다. 종류별 최대 1,000개를 보관해 무료 저장 범위를 제한합니다.
- 공개 검색 페이지에서 정확한 날짜를 얻지 못하면 수집 시각을 게시일로 꾸미지 않습니다. 네이버 관련 미니 기사는 다른 언론사와 잘못 연결될 수 있어 검증된 주 기사 카드만 읽습니다.
- 외부 URL은 http(s)·공개 호스트만 허용하고 사용자 정보/비표준 포트/사설 주소는 거절합니다. 브라우저 링크는 noopener/noreferrer, 이미지에는 no-referrer와 실패 대체 표시를 사용합니다. 검색 장애·차단을 우회하거나 인증 쿠키를 요구하지 않습니다.

## 검증

실제 공개 네이버 HTML에서 언론사와 매칭되는 주 기사 10개(썸네일 9개), 블로그 20개(썸네일 20개, 회사 외 작성처 14개)를 확인했습니다. 테스트는 합성 자료만 사용합니다. 프론트엔드·Worker 빌드, 전체 브라우저/집계 32개, 로컬 Worker/D1 28개 검사 통과. 중복/9개 키워드 진행/이전 기록/잠금/캐시/실패·빈 결과 구분/개인 블로그/3열·320px 레이아웃을 포함합니다.
